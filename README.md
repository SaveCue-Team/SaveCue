# SaveCue

**Save Smarter. Find Faster. Revisit What Matters.**

SaveCue is an Android application designed to help users save, organize, search, and revisit content from multiple platforms, including Facebook, YouTube, TikTok, and web browsers.

The project focuses on addressing the common problem of saving useful content but forgetting to revisit it.

## Project Overview

SaveCue provides a centralized solution for managing saved content through Android's native sharing capabilities.

### Core Features

- **Quick Saving:** Save URLs, images, and files using Android Share Intent.
- **Content Organization:** Manage saved content with aliases, tags, and viewing statuses.
- **Search & Filter:** Find content using titles, filenames, aliases, tags, or statuses.
- **Reminder Notifications:** Receive reminders about unfinished content.
- **Content Revisit:** Reopen saved content in supported source applications.

## User Research

The initial research collected **47 survey responses** to investigate users' content-saving habits, difficulties retrieving saved information, and interest in a centralized content management solution.

The findings are used to inform product decisions, validate critical assumptions, and prioritize MVP features.

**Research Evidence:** [Survey Summary](research/survey-summary.md)

The original survey responses are not publicly shared because they may contain participants' personal contact information.

## MVP Scope

The initial Android MVP focuses on four main capabilities:

1. Saving content from external applications.
2. Organizing and searching saved content.
3. Tracking content viewing status.
4. Reminding users to revisit unfinished content.

Advanced capabilities such as AI summarization, OCR, full-text search, and multi-device synchronization are excluded from the initial MVP.
